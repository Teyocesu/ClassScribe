# ClassScribe v0.9.0 — ASR confiable

## Alcance

v0.9.0 refuerza el pipeline de transcripción sin cambiar el contrato de
captura durable ni la arquitectura existente. La captura continúa aunque el
ASR tarde, falle o quede no disponible para la sesión.

- macOS usa el VAD Silero ya disponible en FluidAudio; Windows usa el VAD
  Silero integrado en Whisper.net 1.9.1.
- Si el VAD confirma cero voz, la ventana/audio devuelve transcript vacío sin
  ejecutar ASR; con voz presente se conserva el audio original y se filtran
  sólo los segmentos sin overlap. Si el VAD falla, el flujo ASR funciona
  fail-open como antes. Los resultados vacíos nunca borran texto previo ni
  correcciones humanas.
- Los reintentos live usan backoff finito. Al agotarlo, el estado es
  `unavailableForSession`; el audio queda disponible para reprocesar.
- La preparación de modelos se hace fuera del hilo de captura/UI y se
  comparte entre usos concurrentes.
- El backlog live sigue limitado por los buffers existentes; el audio durable
  permanece como fuente de verdad.

## Persistencia e idioma

Se conservan `master.raw`/`source.wav`, el transcript ASR original y los
overlays de edición. Se mantienen los idiomas es/en/fr y el vocabulario
técnico existente.

## Fuera de alcance

No se rediseñan captura, diarización, UI, persistencia ni workflows de CI. No
se añade un motor de streaming paralelo ni se presentan como gates físicos las
validaciones que este host no puede ejecutar.
